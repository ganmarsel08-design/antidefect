# Реестр правил Антидефекта (черновик 0.1)

`rules.json` — правила с источником (протокол РК, раздел, цитата), условиями применимости, нужными данными, логикой и статусом.
Статусы: проверено / требует сверки / не использовать. Сейчас все — «требует сверки».

Проверка: `python3 registry/validate.py registry/rules.json <neo-pro>/data/protocols.json` — убеждается, что каждая цитата дословно есть в тексте протокола.

Покрыто: Сепсис (№185, 13 правил), РДС (№4, 16 правил). Следующие по плану: БЛД, НЭК, питание, желтуха, трансфузии, ГИЭ.
Правила в код Антидефекта пока не подключены.
