# Слепое тестирование извлечения №1 — оценщик (вне программы)

Каталог не входит в медицинскую программу и не меняет её. Измеряется замороженная версия `13a21b3` (extract 0.7.0-stage7).

- `kit/` — комплект 1.4:
  - метод `blind1-method.md` (1.4);
  - задание автору `blind1-author-package.md` (1.2);
  - оценщик `scorer/`, инструменты `tools/`;
  - единый манифест `freeze/blind1-manifest-1.4.json`, SHA-256 `84c7785d0897e9704cd45ca309f1bc93ab6c9c027e7ea4314ce0380d48a8289e`;
  - протоколы изменений, результаты тестов, diff 1.3 → 1.4.
- `releases/` — архивы комплекта 1.1–1.4 в том виде, в каком они передавались на аудит.

**Порядок.**
1. Независимый автор (отдельная беседа ChatGPT, без доступа к репозиторию) получает только `kit/blind1-author-package.md`.
2. Набор `blind1-source.zip` в репозиторий **не загружается** до утверждения отчёта.
3. Набор принимается так: формальная проверка (`scorer/validate.py`), затем заморозка (`scorer/freeze.js`).
4. Прогон выполняется на отдельной выгрузке программы `git worktree add <путь> 13a21b3…`, путь передаётся как `--repo`. HEAD ветки с этим каталогом не равен базовому коммиту, поэтому прогон из неё оценщик остановит.

CI: задача «Оценщик blind1 1.4» в `.github/workflows/tests.yml`. Она проверяет хэш манифеста, целостность комплекта и программы 13a21b3, воспроизводимость пакета автора и выполняет 41 технический тест.

Только синтетические данные. Врачебные оценки не заполняются, окончательных клинических заключений нет.
