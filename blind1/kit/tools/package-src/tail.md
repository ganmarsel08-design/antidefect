
## 8. Правила протоколов, к которым относятся истории (30 правил)

## 9. Что передать

Один архив `blind1-source.zip`:

```
histories/СЛП-РДС-01.docx … histories/СЛП-СЕП-05.txt   (15 файлов)
docx-text/СЛП-РДС-01.json …                            (10 эталонов чтения DOCX)
blind1-gold.json
manifest.json      {"files":[{"name":…, "sha256":…}], "produced_elements":[…], "not_produced":[…], "counts":{…}}
author-notes.md    краткое описание замысла каждой истории и самопроверка
```

В `counts` — фактическое число каждого приёма из раздела 3 и каждого типа ловушек.

**Самопроверка перед передачей** (результат — в `author-notes.md`):
1. Каждая `quote` дословно присутствует в своём файле (в DOCX — в указанном элементе).
2. Все `fid`, `tid`, `ueid`, `mid` уникальны. Каждое `same_as` и `superseded_by` ссылается на существующий факт.
3. Каждое значение соответствует типу и допустимым значениям поля. Даты-время — с `+05:00`.
4. Минимумы раздела 3 и требования раздела 4 выполнены, либо недостающее перечислено.
5. В историях нет реальных людей и нет текста, скопированного из описаний полей раздела 7.
6. Значения не вычислялись и единицы не пересчитывались.
7. Для каждого DOCX есть `docx-text/<ID>.json`; его абзацы и ячейки дословно совпадают с документом, все дополнительные элементы перечислены в `unread`.
