## 3. Неоднозначные положения — требуется решение врача

Неоднозначность с пометкой «блокирует» переводит правило в состояние **«Неоднозначность — ожидает экспертного решения»**: до решения эксперта программа не пишет ни «совпадает», ни «отличается». «Всегда» — при любом применимом случае; «при условии» — только в описанной ситуации. Неблокирующие вопросы (класс нормативности, способ документирования) показываются эксперту, но наблюдение формируется.
