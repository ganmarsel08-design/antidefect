Что проверяют тесты:
- изменённая цитата (подмена дозы) ловится по SHA-256; выдуманная цитата с пересчитанным хэшем не находится в PDF; неверная страница указывается вместе с правильной;
- нельзя пометить правило подтверждённым без записи эксперта, базу — аутентифицированной, решение по неоднозначности — без эксперта; класс «противопоказано» требует этого слова в цитате;
- редакция, doc_id и SHA-256 PDF совпадают с реестром этапа 4;
- на синтетических случаях: совпадение, отличие, «нет данных», неприменимость, граничные значения (ГВ 26 нед.), оговорки самой цитаты (интервал 8 ч при очень тяжёлом состоянии), противоречия внутри протокола (НЭК 2а; сепсис 7 vs 10 дней);
- ни один результат не окончательный: `final_conclusion: null`, статусы только «Требуется оценка эксперта» / «Недостаточно данных», даже при поддельной базе `authenticated: true` и правиле «подтверждено» с записью эксперта; итог, переданный во входных данных, игнорируется;
- обоснование отклонения врачом сохраняется и передаётся эксперту, но автоматически не превращает отличие в «обоснованное отклонение»; обоснование без автора — неполное;
- случаи без `synthetic: true` или с полями ФИО/ИИН отклоняются; входные данные и база не изменяются.

## 5. Ограничения пилота
- Правила извлечены вручную (Claude) из трёх PDF; полнота не заявляется — это 10 положений на протокол, а не весь протокол.
- Для 12 правил без модального слова класс выставлен предварительно и в каждом поставлен вопрос эксперту; проверка `verify_rules.py` не пропускает такое правило без этого вопроса.
- Классы нормативности выставлены по словам цитаты («показано», «должен», «следует», «рекомендуется», «не рекомендуется»), формулировки без модального слова отмечены; окончательный класс определяет эксперт.
- Машинные условия — буквальное прочтение; там, где протокол не даёт порога (гипокапния, «немедленно», «риск РДС»), правило требует отметки врача.
- Таблицы PDF (дозы, уровни доказательности) извлекаются с потерей структуры; уровни доказательности взяты только для двух правил, где строка таблицы читается однозначно.
