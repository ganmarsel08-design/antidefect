## Исправления по замечаниям независимого аудита PR №8 (20.11)

1. Выгрузка запрещена, если данные изменены после последнего расчёта (а также до расчёта и до решения по всем сведениям); причина показывается рядом с кнопкой.
2. DOCX: лимиты проверяются по оглавлению архива без распаковки (`checkCRC32:false` при загрузке); затем распаковываются только нужные элементы,
   потоком, с контролем фактического объёма (не больше заявленного и общего лимита) и проверкой CRC-32.
3. Два независимых признака: «решение есть по всем извлечённым сведениям» и «исходный документ прочитан полностью». При неполном чтении —
   предупреждение на экранах карточек и сводки и в выгрузке; формулировка о полной проверке не используется.
4. В выгрузке — комментарий эксперта, обоснование отклонения, привязанный фрагмент истории (только точное совпадение с текстом) или пометка
   «введено вручную и не связано с документом». Обоснование не меняет результат движка и не считается клинически подтверждённым.

## Известные ограничения (нерешённые вопросы)

Программа не готова к обработке реальных историй болезни: этап 7 — пилот только на синтетических данных.


- Точность извлечения пока подтверждена только на девяти историях разработки: шаблоны настроены на 9 историй, по которым и проверяются. Это проверка на тех же данных, на которых шли настройки;
  на других формулировках извлечение пропустит сведения (новых значений оно не выдумывает). Нужен отложенный набор историй.
- Движок принимает одно значение для некоторых параметров, изменяющихся во времени (`gi_passage_restored`); динамика показывается, выбор делает врач (правило NEC-003 не менялось).
- Обоснование отклонения и комментарий эксперта сохраняются в журнале и выгрузке, но в движок не передаются.
- Повторяющиеся текстовые фрагменты делают привязку обоснования неоднозначной. Такая привязка помечается на экране и в выгрузке («место однозначно не установлено»)
  и не выдаётся за установленный источник; врач должен уточнить цитату.
- Журнал и решения врача не сохраняются после закрытия страницы (хранение — следующий этап).
- Признак «грамотрицательный посев» предлагается по короткому справочнику возбудителей; подтверждает врач.
- Выгрузка — HTML-документ с расширением .doc (Word открывает); имя файла латиницей.
- PDF не поддерживается (отдельный этап). Сценарий `audit-ui.scenario.js` этапа 4 в CI не запускается.
