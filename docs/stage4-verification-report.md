# Этап 4, шаг 1: сверка 29 протоколов с официальными источниками (отчёт 18.11.2026, ред. 3)

Кандидат реестра: `registry/protocols-registry.json` (версия 0.2-candidate). Проверка: `python3 registry/verify_registry.py registry/protocols-registry.json <neo-pro>/data/protocols.json`, тесты правил: `python3 -m unittest registry/test_registry.py`.

## Источники
- Официальный каталог клинических протоколов ННЦРЗ: https://nrchd.kz/clinical-protocols/catalog (1195 документов, загрузка порциями через JavaScript).
- Протоколы заседаний ОКК: https://nrchd.kz/quality-commission (опубликованы не все заседания).
- Вторичный источник (только как указатель, не как подтверждение): diseases.medelement.com.

Сбор выполнен автоматически (поиск и чтение сайта). Это доказательства для эксперта, а не подтверждение: у всех 29 протоколов статус в реестре остаётся «не проверен», пока эксперт не подтвердит его по официальному документу.

## Обновление после проверки PR №6
- **НЭК №154** (23.12.2021): метаданные исправлены в реестре — категория пациентов «новорожденные» (по официальному документу). №154 не помечен заменённым. **НЭК №185** (28.07.2023) — приоритетный кандидат для помощи после 28.07.2023. Выбор по дате помощи: `editions_for(reg, 'nek', дата)`.
- **Девять документов**, для которых независимая проверка сообщила об официальных PDF на nrchd.kz (НЭК №185, ПП №185, энтеральное питание №177, РДС №4, лечебная гипотермия №10/2014, реанимация недоношенных №10/2015, ПЛГН №4, геморрагическая болезнь №1, тератома №238): точные URL не переданы, повторный поиск по сайту их не нашёл. В реестре записаны как `reviewer_claim`. **Ред. 3:** URL получены и проверены — 6 подтверждены, 3 отдают 404 (раздел ниже).
- **Идентификатор:** `doc_id` (тип:название:дата). Номер заседания повторяется: №10 и №185 — у пяти протоколов каждый; №10 принадлежит двум разным органам (Экспертная комиссия 2014 и Экспертный совет 2015).
- **Тип протокола** установлен по официальным шапкам: диагностика и лечение — 17, медицинское вмешательство — 5, не установлен — 7 (ред. 3).
- **Контрольные суммы:** сохранены SHA-256 текста протокола в базе и дословной шапки из официального источника. SHA-256 самих PDF-файлов не сохранён: из рабочей среды сайт недоступен для скачивания, а сервис чтения отдаёт текст, не байты. Нужна выгрузка файлов или их хэши.
- **Актуальность (`currency_check`)** — «не проверена» у всех 29.

## Сверка по 9 URL проверяющего (18.11.2026, ред. 3)
Проверяющий передал точные URL. Каждый URL открыт заново, прочитаны первые 2 страницы PDF (шапка, п. 1.1–1.5). Байты PDF получить не удалось: из рабочей среды сайт nrchd.kz закрыт, сервис чтения отдаёт текст. Поэтому найденным документам присвоен результат «официальный источник найден, файл не верифицирован». SHA-256 файлов не заполнен; хэш текста вместо него не подставлялся.

- Три URL с путём `/docs/clinic_protocol/<год>/...` (старый раздел сайта) сейчас отдают страницу «404: Страница не найдена». Документы по ним не получены; отменёнными они не считаются.
- НЭК №185 теперь найден на официальном сайте. **НЭК №154 не помечен отменённым или заменённым**: выбор редакции — по дате помощи, решение о замене — за экспертом по официальному подтверждению.
- Для 4 документов тип установлен по шапке, `doc_id` обновлён (КП-ДЛ / КП-МВ).
- Модуль отклонений получает эти записи только через загруженный реестр; `official_evidence` = «официальный источник найден, файл не верифицирован» не входит в список официальных доказательств, поэтому положительный вывод по ним заблокирован.
- Расход: 15 кредитов Firecrawl (6 × 2 стр. PDF + 3 × 404).

**Вопрос на согласование.** Семь записей «официальный PDF, шапка прочитана» из ред. 1 получены тем же способом (текст через сервис чтения, без байтов файла). По новому правилу их, вероятно, тоже следует перевести в «официальный источник найден, файл не верифицирован». Пока не менял — нужно решение проверяющего.

- Экстракорпоральный метод лечения грамм-негативного сепсиса (Р36) — найден на официальном сайте, шапка не прочитана

## Замечания для эксперта
- «НЭК (педиатрия)» №154 от 23.12.2021: в официальном документе название «Язвенно-некротический энтероколит», категория пациентов — **новорожденные**. В базе он подписан как протокол для детей старше периода новорожденности. Нужно решить, какой из двух НЭК-протоколов (№154 или №185) применим и не заменяет ли один другой.
- «Ретинопатия» №166: в официальном PDF строка «пересмотр 2019 г.» при одобрении в 2022 г. — так в первоисточнике.
- «Уход за ребенком» и «Гипотермия цепочка» сопоставлены по номеру, дате и коду МКБ с официальными «Уход за здоровым новорожденным» и «Гипотермия новорожденных (тепловая защита)».
- 7 протоколов (РДС №4/2016, ГИЭ №74, желтуха №171, родовая травма №35, диабетическая фетопатия №27, геморрагическая болезнь №1, реанимация недоношенных 2015) на официальном сайте не найдены. Это не значит, что они отменены.
- Крестцово-копчиковая тератома №238: название «у новорожденных», но в п. 1.5 категория пациентов — «дети». Нужно решение эксперта о применимости к ОРИТН.
- Лечебная гипотермия №10/2014 утверждена Экспертной комиссией по вопросам развития здравоохранения МЗ РК (не ОКК), как и другие протоколы №10 от 04.07.2014.
