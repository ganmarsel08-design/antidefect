# План / назначено / введено / отменено: поля, интерфейс и влияние на правила (этап 3 issue #10)

Только синтетические данные. Словарь полей, правила и пороги не менялись.

## Разделение
| Уровень | Что означает | Откуда | Входит в случай |
|---|---|---|---|
| `*_given` антибиотиков | по словарю: «Назначен гентамицин», «Назначен бензилпенициллин», «Метронидазол включён в терапию» | прямая запись назначения/введения; не при плане, условии, «не назначен», «отменён до введения», «фактически не вводился» | да, после подтверждения врача; в интерфейсе пометка «факт и время введения подтверждаются отдельно» |
| `immunoglobulin_given` | по словарю: «Введён иммуноглобулин» | только «введён»; `false` только «не вводился» | да, после подтверждения |
| `first_abx_dose_administered_at` | «Время фактического введения первой дозы» | только прямая запись «введена первая доза» со **своим** временем (`event_time`); время записи — `document_time`, только индивидуальное подтверждение (PR №15) | да, после подтверждения |
| `medication_events` (новое, вне словаря) | статус каждого упоминания препарата: план / назначено / введено / отменено / не введено / упомянуто; время — только `event_time` у глагола введения | извлекатель | **нет** — только для сведения врача, блок «Препараты в тексте» |

## Правила, читающие эти поля
| Правило | Поля | Смысл, которого требует правило | Источник в извлечении |
|---|---|---|---|
| SEP-001, SEP-002, SEP-007 | `first_abx_dose_administered_at` | **фактическое введение** | только «введена первая доза» + своё время; время записи — требует подтверждения |
| RDS-008 | `antibiotics_started` + времена | начало АБТ | «начата/начаты АБТ», «введена первая доза»; не при «решено начать» |
| SEP-005, SEP-006 | `*_given`, доза, интервал | **назначение** (проверка назначенной дозы) | назначение или введение; не при плане/отмене/невведении |
| NEC-007 | `metronidazole_given` | «включён в схему» | «начаты … метронидазол», доза при назначении; не при плане/условии |
| SEP-003 | `immunoglobulin_given` | **введение** | только «введён» |
| SEP-004 | `initial_empirical_regimen` | стартовая схема | «первая доза / эмпирическая схема: …» |
| NEC-008, SEP-008…010 | `abx_course_*` | длительность по введённым дозам | «первая доза … введена», «последняя доза», «курс завершён»; время записи — требует подтверждения |
| RDS-002, RDS-003, RDS-009 | `surfactant_*` | введение | «введён/введена» (не «введение … отложено»), не при «?», плане |

Вывод: ни одно правило не выводит факт введения из поля «назначен»; правила, которым нужно введение, читают только поля введения, а их время по записи врача теперь требует отдельного подтверждения.
