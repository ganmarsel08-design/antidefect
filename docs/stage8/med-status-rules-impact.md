## Статус у конкретного препарата (ревью ChatGPT к 8622515)

Раньше статус определялся проверкой всего предложения на глагол. Теперь глагол связывается с конкретным препаратом:
- Предложение делится на части по «,», «;», «а», «но», «однако», «затем». Препарат получает статус маркеров **своей** части.
- Часть без своего маркера наследует статус предложения, только если в предложении он один. Иначе статус — **«не определён»**, с пояснением.
- Часть без препарата («введён не был») уточняет предыдущую часть, только если в ней один препарат. Иначе — «не определён». Так же работает следующее предложение без препарата («Введено не было.»).
- Новые статусы:
  - «не назначено» — «не назначен»;
  - «указание не вводить» — «не вводить»;
  - «начато (введение дозы не подтверждено)» — «начат» больше не считается введением;
  - «не определён» — неоднозначность.
- Таблица определяется по заголовку: «назнач» → назначено, «введ» → введено, иначе (например, таблица посевов и чувствительности) → «упомянуто». Маркеры в самой строке («не назначен») сильнее заголовка.
- Скопированный текст и текст, названный ошибочным (`guardSpans`), не используются. Конец ошибочного участка теперь распознаётся и по «верно:».
- Время введения — только у маркера введения **этого** препарата и только своё время события.
- Блок по-прежнему только для сведения: тест сравнивает случай и `derive` с блоком и без него, они совпадают.

## Трассировка SEP-005/006: словарь → derive → правило (без изменения правил)

| Шаг | SEP-005 (бензилпенициллин) | SEP-006 (гентамицин) |
|---|---|---|
| Применимость | `early_onset_sepsis_suspected`, `benzylpenicillin_given` («**Назначен** бензилпенициллин»), `meningitis = false` | `early_onset_sepsis_suspected`, `gentamicin_given` («**Назначен** гентамицин») |
| Входы дозы | `benzylpenicillin_dose_mg` (разовая доза), `weight_kg` («масса тела **на дату назначения**»), `weight_measured_at`, `benzylpenicillin_prescribed_at` («время **назначения**»), запись `benzylpenicillin_dose_mg_kg` | `gentamicin_dose_mg` («начальная доза»), `weight_kg`, `weight_measured_at`, `gentamicin_prescribed_at`, запись `gentamicin_initial_dose_mg_kg` |
| derive | `*_dose_per_kg` = мг ÷ масса, если масса измерена в тот же календарный день и **не позже назначения**; иначе записанная мг/кг; иначе «нет данных» | то же |
| Проверка | `benzylpenicillin_dose_per_kg = 25`; `benzylpenicillin_interval_h` 12 (8 при очень тяжёлом состоянии) | часть «доза»: `gentamicin_dose_per_kg = 5`; часть «интервал»: `gentamicin_interval_h` 36 (короче при `very_ill` и грамотрицательном посеве) |

Вывод:
- **Доза** в SEP-005/006 проверяется как **назначенная**: применимость по «назначен», масса на дату назначения, время назначения. Для этих частей поле «фактически введён» не требуется, правила менять не нужно.
- Неясно описание словаря `gentamicin_interval_h` («Интервал между первой и второй дозой гентамицина»). Его можно прочитать и как **назначенный** интервал, и как **фактический** интервал между введёнными дозами. Сейчас извлечение заполняет его из записи назначения («каждые 36 ч», «вторая доза через 36 ч»): это назначенный интервал, а не измеренный по временам введения. Если правило должно проверять фактический интервал, нужны времена введения первой и второй доз. Это вопрос к рецензенту и владельцу; без решения ничего не меняется.
- Возможное версионированное расширение, **только предложение**: отдельные поля аудита введения (`*_first_dose_administered_at`, `*_second_dose_administered_at`) в новой версии словаря, со своей трассировкой и тестами. Существующие поля и правила не меняются.
