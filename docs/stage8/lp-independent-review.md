# Разбор 37 «ложных извлечений» на наборе №1 заново, по описанию поля (этап 4 issue #10)

Только синтетические данные. Набор №1 — **регрессионный, не слепой**. Исходный эталон `blind1-gold.json` и результаты `results-v1` **не переписываются**; таблица — разбор исполнителя для рецензента.

Метод (заново, независимо от прошлой таблицы `lp-review-set1.md`): для каждого значения, которого нет в эталоне, — описание поля из словаря, цитата с контекстом, вывод в одной из трёх категорий:
- **соответствует** — значение прямо записано в тексте и подходит под описание поля;
- **время записи** — значение равно времени записи врача, а не прямо названному времени события; после PR №15 такое значение помечается `document_time` и попадает в случай только при индивидуальном подтверждении врачом;
- **неоднозначно** — текст допускает другое прочтение; значение оставлено альтернативой.

Ограничение независимости: разбор делает тот же исполнитель, что писал извлекатель. Окончательная оценка — за рецензентом; набор №2 слепой проверкой это не заменяет.
