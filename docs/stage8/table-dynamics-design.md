# Динамика КОС / ИВЛ / FiO2 и табличные данные — проект и первая реализация (этап 6 issue #10)

Только синтетические данные. Словарь, правила и пороги не менялись.

## Поля словаря и правила
| Поле | Описание (словарь) | Правило |
|---|---|---|
| `blood_gases` | газы крови за время ИВЛ: `{drawn_at, paco2_mmhg, ph}` | RDS-010 (газы есть; гипокапния по порогу; реакция врача) |
| `vent_changes` | изменения настроек ИВЛ: `{at, parameter, from, to}` | RDS-010 (время от гипокапнии до изменения) |
| `xrays` | рентгенограммы: `{at, position, reason, result}` | NEC-006 (контроль через 48 ч, раз в неделю, вертикально/латеро при ухудшении) |
| `fio2` | FiO2 во время **стабилизации** | RDS-003 |

## Разбор таблиц (реализовано, `extract.js` 0.8.2-dev)
1. Таблица = строка-заголовок с «|» и следующие строки с тем же числом ячеек. Колонки узнаются по заголовку (дата/время; pH; pCO2 с единицей; PIP; PEEP; FiO2 с единицей; ЧД; исследование; положение; показание; заключение).
2. Строка — источник, только если в её колонке времени есть **своя дата и время**; время строки — `event_time` (время забора / исследования). Строки без даты-времени, скопированные и с неполными ячейками — пропускаются.
3. Единицы: pCO2 — только мм рт. ст. (в кПа — не извлекается, пересчёта нет); FiO2 — только доля 0,21–1,0 (проценты не приводятся к доле). Значения вне физиологически возможного диапазона (pH 6,5–7,8; pCO2 10–150) — не извлекаются.
4. `vent_changes` из таблицы **вычисляются** по соседним строкам (параметр изменился) — помечаются «вычислено по соседним строкам таблицы — подтвердите» и требуют индивидуального подтверждения врачом.
5. Рентгенограммы: положение (горизонтально / вертикально / латеро), показание (экстренно → urgent, планово/контроль → planned), заключение как записано.

## Не реализовано (следующие шаги, нужны решения)
- **FiO2 в ОРИТН по времени.** Поле `fio2` в словаре — только стабилизация; динамику FiO2 вне родзала держит `vent_changes`. Отдельное поле «FiO2 по времени» — изменение словаря (решение владельца/рецензента).
- **КОС и ИВЛ в тексте дневника** (не таблицей) — сейчас только формулировки этапа 7 «ДАТА ВРЕМЯ — pH …, PaCO2 …» и «PIP снижен с … до …».
- **Движок принимает одно значение** для меняющихся во времени скалярных параметров — известное ограничение; списки (`blood_gases`, `vent_changes`, `xrays`) передаются целиком.
- Набор №1 эту часть почти не проверяет (полнота по нему не изменилась); проверка — набор №2.
