# Этап 4: подключение и верификация реестра клинических протоколов РК (план)

Статус: план, не реализован. Отдельный этап после принятия этапа 3. Реальные медицинские данные не используются до отдельной проверки безопасности.

## Цель
Получить реестр применимых протоколов, у которого полнота и актуальность сверены с официальными источниками, чтобы движок мог снимать блокировку положительного вывода (уровень «сверено с официальными источниками», ТЗ раздел 18).

## Исходные данные
- `neo-pro/data/protocols.json` — 29 протоколов (только чтение). Сейчас у всех статус «не проверен».
- Официальные источники: опубликованные клинические протоколы МЗ РК (Республиканский центр развития здравоохранения, протоколы ОЭК), правовая база с номерами и датами приказов. Конкретный перечень источников утверждает эксперт.

## Шаги
1. **Модель записи реестра:** номер, название, дата утверждения, редакция, период действия (с — по), статус (действует / заменён / не проверен), заменивший документ, ссылка на официальный источник, дата сверки, кто сверял, хэш текста.
2. **Сверка каждого из 29:** найти официальный документ, подтвердить номер и дату, установить, действует ли редакция и на какие даты. Ничего не заполнять предположениями: не найдено — «не проверен».
3. **Применимость к ОРИТН:** перечень протоколов, которые должны входить в реестр для неонатологии; отсутствующие — в `missing_applicable`.
4. **Цитаты:** проверка, что цитаты правил (`registry/rules.json`) дословно есть в сверенной редакции (`registry/validate.py`).
5. **Верифицированная версия реестра:** неизменяемый снимок с номером версии и журналом сверки; уровень «сверено» присваивается только ей.
6. **Подключение к движку:** выбор протоколов и редакций на дату помощи из реестра, а не из ручного ввода; подтверждение полноты ссылается на версию реестра.
7. **Тесты:** синтетические случаи на смену редакции, заменённый протокол, неполный реестр, расхождение цитаты.

## Вне этапа 4
Авторизация и защищённый журнал, серверная подпись подтверждений, проверка PubMed через API, инструкции препаратов (НЦЭЛС и МИ), работа с реальными историями — отдельные этапы с проверкой безопасности.
